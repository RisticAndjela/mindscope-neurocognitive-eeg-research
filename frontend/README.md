# MindScope Frontend

Angular frontend for MindScope.

## Design

Dark computational neuroscience workspace with purple/blue accents, animated neural hero, public project pages, public blog, and a login entry for future private editing.

## Run

```bash
cd frontend
npm install
npm start
```

Backend expected at:

```txt
http://127.0.0.1:8000/api/v1/research
```

## Routes

- `/`
- `/projects`
- `/projects/:id`
- `/blog`
- `/blog/:id`
- `/login`
